# Changelog

All notable changes are listed here. Versions follow [Semantic Versioning](https://semver.org/); below 1.0, a breaking change to the provider's keys or behaviour bumps the minor version.

## 0.1.0 - 2026-11-11

First public release.

- Finds the current GZM ZTM schedule files through the publisher's data portal.
- Realtime trip updates, vehicle positions and alerts, with a stable vehicle key.
- Fleet livery for vehicle markers, and the publisher's attribution.
